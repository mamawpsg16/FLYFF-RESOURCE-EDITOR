// Free PK Time - scheduled window where PK has no penalty and monster EXP is multiplied.
//
// While a window is open:
//  - attacking a player does not turn you pink, killing one adds no PK points
//    (players who are already chaotic stay chaotic)
//  - a player killed by another player drops no items and loses no EXP
//  - monster EXP is multiplied by EXPRATE
// Safe zones, towns and the PK level limit (PKSetting.inc LIMITE_LEVEL) still apply.
//
// DURATION   length of one window in minutes (1 - 1440)
// EXPRATE    monster EXP multiplier while open (1.5 = x1.5)
// WARNING    "starts in N minutes" chat notice before each window, 0 = off
// SCHEDULE   one line per start time:   day   hour   minute
//            day: 0 = every day, 1 = Sunday, 2 = Monday ... 7 = Saturday
//            times are the server PC's local time
//
// GM commands: /freepkstart (/fpks) opens a window now, /freepkstop (/fpkst) ends the
// current one (the next scheduled window still opens as normal).
// Restart the WorldServer after editing this file.

DURATION	60
EXPRATE		1.5
WARNING		5
