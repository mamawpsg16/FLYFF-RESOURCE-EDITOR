// Penya Table - Penya a monster gives per kill, by monster level.
//
// For the ranks listed under RANKS, this replaces the DropGold(min, max) values in
// propMoverEx.inc. Everything else still multiplies on top, exactly as before:
//  - the level-gap cut (killer 3-4 levels above: 80%, 5-7 above: 65%, 8+ above: 50%)
//  - Event.lua "Server Rates" SetGoldDropFactor (x10 now)
//  - Anarchy and Penya Rate items (St. Patrick's Day Cloak +50%)
// Every rank not listed keeps its propMoverEx.inc DropGold.
// A monster with no DropGold line still gives no Penya.
//
// LEVELS   level   minGold   maxGold
//  - these are BASE amounts: the player gets them x10 (Server Rates) at the same level
//  - the curve grows about 5% per level, the same way monster EXP does
//  - levels between two rows are filled in on a straight line, so every level gives
//    a little more than the one below; below the first row the first row is used,
//    above the last row the last row is used
//
// RANKS    rank   percent   mode
//  - rank: 1 = LOW, 2 = NORMAL, 3 = CAPTAIN, 4 = BOSS (giants), 5 = MIDBOSS, 7 = SUPER
//  - percent of the LEVELS amount that rank gets; leave a rank out to keep its DropGold
//  - mode 0: the table replaces DropGold
//    mode 1: whichever is higher, the table or DropGold - for bosses, some of which
//            (Skeldevil, Behemoth, Kraken ...) already pay millions from DropGold
//  - every row needs all three numbers
//
// WORLDS   worldID   percent
//  - multiplies the table amount for monsters killed in that map (not listed: 100)
//  - world IDs are in defineWorld.h (5 = WI_WORLD_DARKRARTESIA, Dark Traseia)
//  - Dark Traseia is THE Penya-farming map: x2 of the same level anywhere else.
//    Madrigal is for levelling, Monster Hunt and giant hunting.
//
// Restart the WorldServer after editing this file.
